# CATIA

This folder collects CATIA mechanical design work, including 3D part models, assemblies, modeling exercises, screenshots, and engineering drawings.

## Suggested contents
- Native CATIA files (`.CATPart`, `.CATProduct`, `.CATDrawing`) when appropriate
- Screenshots or rendered views of completed models
- Exported drawings or neutral CAD formats when useful
- Short notes describing design intent and modeling techniques

Add only work you created or are authorized to share.
